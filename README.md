# ШМАВИТО

Публичный каталог предложений Avito для сообщества STEEL. Репозиторий находится на первом этапе разработки: интерфейс работает на демонстрационных данных, backend-контракты и база подготовлены к подключению.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Откройте `http://localhost:3000`.

## Инфраструктура

```bash
docker compose up -d
```

Команда поднимает PostgreSQL, Redis и MinIO. Скопируйте `.env.example` в `.env.local` и замените секреты перед подключением backend.

## Реализовано в UI

- приветственный экран STEEL и адаптивный каталог;
- поиск, категории, сортировки и фильтр непросмотренных;
- персональная отметка просмотра в `localStorage`;
- лайки, карточка объявления, комментарии и ответы в демо-режиме;
- форма предложения с валидацией ссылки Avito и имитацией импорта;
- личный кабинет с заявками и уведомлениями;
- рабочий прототип панели модерации;
- Prisma-схема основной модели данных;
- Docker Compose для PostgreSQL, Redis и S3-совместимого MinIO.

## Следующий этап

Twitch OAuth, серверные сессии, реальные CRUD/API, импорт публичных метаданных Avito с ручным fallback, файловое хранилище и фоновые задачи.

Все карточки и показатели текущей версии являются демонстрационными.
